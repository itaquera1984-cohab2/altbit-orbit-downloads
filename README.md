# Altbit Orbit — atualizações

O código-fonte é mantido no repositório privado `itaquera1984-cohab2/altbit-orbit`.
Este projeto público contém somente documentação de distribuição e releases com binários.

- Aplicativo: Windows 10/11 x64, portátil, com .NET incorporado.
- Download: [Releases](https://github.com/itaquera1984-cohab2/altbit-orbit-downloads/releases/latest).
- Feed: https://altbit-orbit-updates.vercel.app/release.json .
- A versão 0.6.0 inclui transferência de arquivos entre Windows e aviso de reconexão por disponibilidade na rede.

Extraia o ZIP comum numa pasta nova e abra AltbitOrbit.exe nos dois Windows.
`Orbit-update-VERSAO.zip` é o pacote para o botão Atualizar, com assinatura interna de publicação.
Essa assinatura não equivale à assinatura Authenticode do Windows.

A integração Android continua experimental e ainda precisa de teste físico. O iPhone não é controlado nesta versão.
Os arquivos pessoais vão diretamente pela rede local; este repositório e a Vercel só distribuem o programa e atualizações.
